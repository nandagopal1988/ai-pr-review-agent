# Spring Boot PR Review Agent

An intelligent GitHub Copilot agent for Spring Boot service repositories that reviews pull requests, checks build health, and provides review guidance tailored to service-specific concerns.

## Usage examples

```
@codeReview review this PR for API contract and transaction risks
@codeReview summarize the changes in this Spring Boot pull request
@codeReview check for security issues in this change
```

## Customization

Set these repository variables to tailor the review:
- `SERVICE_NAME`
- `REVIEW_FOCUS`
- `REVIEW_CONTEXT`
- `REVIEW_STANDARDS`
