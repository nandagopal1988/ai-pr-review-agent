# Generic PR Review Agent

An intelligent GitHub Copilot agent that analyzes pull requests, enforces custom review rules, reviews test coverage, and provides LLM-based recommendations for Spring Boot services or other backend services.

## Usage Examples

```
@codeReview analyze PR #123 for security issues
@codeReview review this Spring Boot PR for API and transaction risks
@codeReview what's the coverage impact of the recent changes?
@codeReview list all critical violations in this PR
@codeReview suggest refactoring for this service change
```

## Customization

The agent can be tailored by repository variables or environment values such as:
- `SERVICE_NAME`
- `REVIEW_FOCUS`
- `REVIEW_CONTEXT`
- `REVIEW_STANDARDS`

## Notes

- Keep this file in the repository root so Copilot can discover the custom agent.
- You can also keep `.copilot/codeReviewAgent.md` as an alternative manifest location.
